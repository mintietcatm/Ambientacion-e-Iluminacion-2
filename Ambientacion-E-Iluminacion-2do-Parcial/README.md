# Ambientación e Iluminación II

Abre esta carpeta (la que contiene `Assets`, `Packages` y `ProjectSettings`) desde Unity Hub con **Unity 6.4 `6000.4.9f1`**. Unity restaurará los paquetes del proyecto al abrirlo.

## Recursos de Unity Asset Store

Los paquetes de la tabla se descargan e importan por separado. En Unity, abre **Window → Package Manager → My Assets**, selecciona cada paquete y pulsa **Download** e **Import**. Mantén las rutas de importación y sus archivos `.meta` para que Unity pueda resolver las referencias de las escenas.

| Paquete | Versión usada | Carpeta |
| --- | --- | --- |
| [Sci-Fi Construction Kit (Modular)](https://assetstore.unity.com/packages/3d/environments/sci-fi/sci-fi-construction-kit-modular-159280) | 1.1.0 | `Assets/SciFi Warehouse Kit` |
| [Starter Assets: Character Controllers \| URP](https://assetstore.unity.com/packages/slug/267961) | 2.0.2 | `Assets/Starter Assets` |
| [Vertex Painter](https://assetstore.unity.com/packages/slug/329081) | 1.0.2 | `Assets/Emmanuel` |

Para abrir `Assets/MichelleRamirez_2doParcial/MichelleRamirez_2doParcial.unity` con los modelos y el controlador, importa primero **Sci-Fi Construction Kit** y **Starter Assets**. **Vertex Painter** aporta herramientas de edición y su propia escena de ejemplo.
